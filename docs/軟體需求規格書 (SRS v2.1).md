# 影片廣告偵測與移除工具 — 軟體需求規格書 (SRS)

* **版本**：2.1（OpenAI & Gemini 雙版本深度整合版）
* **專案名稱**：Video Ad Detector & Remover


* **開發語言与環境**：Python 3.12+（使用 `uv` 進行套件與虛擬環境管理）


* **核心影音工具**：FFmpeg / FFprobe（作為外部依賴管理，啟動時自動檢查環境可用性）


* **目標平台**：macOS、Windows 11（本機離線桌面應用程式）


* **介面框架**：PySide6 (Qt for Python)


* **核心開發原則**：先確保單格精確剪輯與影音同步（MVP），再透過「全片場景切換偵測＋持續性分析＋同片樣本比對」極大化人工確認效率。

## 1. 專案背景與目標

### 1.1 背景與目標廣告特徵

目標影片會在正片播放途中插入中插廣告，結束後恢復正片。根據實際樣本，目標廣告具備以下明確特徵：

1. **呈現方式（全畫面取代）**：正片播放時，整個畫面 100% 被廣告圖卡取代（包含固定版型背景、醒目宣傳文字、遊戲圖示、下方字幕及局部背景動畫／閃爍效果），結束後 100% 切回正片畫面。不假設所有影片的廣告都使用單一特定顏色。


2. **持續時間（約 25 秒）**：單次廣告時長通常約為 **25 秒**（系統預設以 15～35 秒作為可調搜尋範圍）。25 秒僅作為偵測與評分之先驗線索，絕不作為固定硬性切除長度。


3. **出現頻率與位置（2～3 次、位置不固定）**：同一部影片中通常出現 **2～3 次**，插入時間點不固定，因此必須執行全片掃描。



### 1.2 核心目標

1. **全片自動掃描**：掃描整部影片，不因找到第一段廣告而停止。採用「場景切換偵測＋片段持續性分析」抓出所有疑似廣告的起訖區間。


2. **優先級排序與去重**：綜合切點強度、時長與版面特徵為候選區間評分排序（優先凸顯最可能的 Top 2～3 個區間），並自動合併或去重高度重疊的候選區間。


3. **同片樣本擴展搜尋**：支援將同一部影片中第 1 個確認的廣告設為「參考樣本」，快速掃描全片抓出其餘同版型的第 2、第 3 段廣告。


4. **影格級精確定位與四格預覽**：精確定位至單一影格（Frame），提供切入與切出前後的「四格邊界對比預覽」與單格微調控制。


5. **正片完整保留與影音同步**：移除多段廣告後合併正片輸出 MP4，確保正片一格不漏、廣告一格不留，且長片尾端影音完全同步、原始檔案完好無損。



### 1.3 非目標（第一版不包含）

* 不承諾完全無人介入的全自動刪除（所有剪輯輸出前必須經過人工確認）。


* 不使用大型深度學習模型、不依賴獨立 GPU、不上傳任何影片或資料至雲端 API。


* 不以「單一特定顏色（如純紅色）」、「字幕存在與否」或「固定切除 25 秒」作為唯一判斷依據。


* 不處理半透明懸浮橫幅或子母畫面等局部覆蓋型廣告。


* 不提供影片特效、字幕編輯、調色或多軌剪輯功能。

## 2. 使用情境與標準工作流程

1. **載入影片**：使用者選擇影片，系統透過 FFprobe 解析影音串流、FPS（判定 CFR 或 VFR）與時間戳記資訊。


2. **全片三階段掃描**：系統掃描全片，執行「快速切點偵測 $\rightarrow$ 15～35 秒持續性配對與評分 $\rightarrow$ 候選邊界前後逐格精確化」。


3. **檢視候選清單**：系統列出候選廣告區間（可切換「依評分排序 Top-N」或「依時間軸排序」）。


4. **四格邊界確認與微調**：使用者點選候選項目，直接透過「廣告前一格、廣告第一格、廣告最後一格、正片恢復第一格」四格對比視圖檢查，必要時點擊 `±1 格` 微調邊界，並將狀態標記為「已確認為廣告」或「已排除」。


5. **同片樣本輔助搜尋（選用）**：若自動掃描漏掉某段廣告，使用者可將已確認的第 1 段廣告設為「參考樣本」，一鍵掃描全片找出其餘相似版型的廣告區段。


6. **跳接預覽與清單確認**：使用者透過「跳過廣告預覽（Jump-Cut Preview）」確認正片接合處流暢度，檢視系統換算出的「正片保留區間清單」與預估輸出總時長。


7. **FFmpeg 精確剪輯與驗證**：FFmpeg 執行裁切、時間戳記重置、合併與必要的重編碼輸出 MP4；完成後自動以 FFprobe 驗證檔案完整性並保存 JSON 專案檔。

## 4. 功能需求（Functional Requirements）

### FR-001：影片載入與環境檢查

* 支援常見容器格式（MP4、MOV、MKV、M4V 等，依 FFmpeg 支援度而定）。


* 載入後顯示：檔案名稱、檔案大小、總時長、解析度、影格率（明確標示 CFR 或 VFR）、總影格數及影音編碼格式。


* 原始影片全程唯讀，嚴禁修改或覆蓋。



### FR-002：影格級定位與索引規範

* 提供：前一格（`-1`）、下一格（`+1`）、前進/後退指定影格數（如 `±5`、`±30` 格）、跳至指定時間戳記、跳至指定影格索引。


* **統一索引規範**：系統內部資料結構與 GUI 介面統一採用 **0-based 影格索引**（第一格為 `Frame 0`），並同時顯示精確時間戳記（`HH:MM:SS.mmm`）。


* **CFR / VFR 定位原則**：CFR 影片以實際解碼影格建立一致索引；VFR 影片必須以實際解碼影格的 PTS 時間戳記定位，嚴禁僅用播放器四捨五入秒數或 `frame_index / nominal_fps` 推算。



### FR-003：全片場景切換掃描

* 每次分析必須完整掃描至影片結尾，不得因找到第一段疑似廣告而提前中止。


* 預設以低解析度（長邊 320～480px）、每秒取樣 2～5 格（參數可調）進行快速掃描。


* 結合場景切換偵測、HSV 色彩直方圖差異與亮度／邊緣結構變化找出全畫面切換候選點集合 $T_{cuts}$。



### FR-004：廣告片段持續性與特徵分析

* **時間窗過濾**：預設廣告目標時長為 **25 秒**，初始候選搜尋範圍為 **15～35 秒**（使用者可於 GUI 調整上下限，或勾選關閉時長過濾以檢視所有長短片段）。


* **區間視覺特徵分析**：檢查切入點 $t_{in}$ 與切出點 $t_{out}$ 之間的畫面是否呈現與前後正片截然不同的視覺狀態。評估主體背景版面與色彩分布的穩定度，但**容許廣告期間存在局部動態動畫、文字閃爍、下方字幕更換或內部次要切換**，不要求廣告每一格完全靜態相同。


* **前後正片呼應分析**：比對 $t_{in}$ 之前與 $t_{out}$ 之後的正片畫面特徵，若前後正片場景具備連續性或高相似度，則提高該區間為中插廣告的評分。



### FR-005：候選區間評分、排序與去重

* 綜合「切入／切出斷層強度」、「時長接近 25 秒程度」、「廣告期間版面特徵穩定度」與「前後正片恢復程度」計算優先級分數。


* 分數僅代表人工檢查優先順序，不代表絕對機率。支援「依評分高低排序（凸顯 Top 2～3 候選）」與「依時間先後排序」切換。


* **去重與合併機制**：對時間高度重疊或因廣告內部小轉場產生的相鄰碎裂候選區間，自動進行合併或去重，避免同一段廣告產生大量重複提示。



### FR-006：候選清單與四格邊界對比視圖（4-Frame Boundary View）

* 候選清單顯示：編號、起訖時間、起訖 Frame Index、持續秒數、優先級分數，以及三種確認狀態（**未確認、已確認為廣告、已排除**）。


* 選取任一候選區間時，主預覽器跳至該位置，且下方**四格邊界檢查區**並排顯示四張關鍵影格：


1. **廣告前一格**（`start_frame - 1`）：應為正片切出前最後一格。


2. **廣告第一格**（`start_frame`）：應為廣告圖卡切入第一格。


3. **廣告最後一格**（`end_frame - 1`）：應為廣告結束前最後一格。


4. **正片恢復第一格**（`end_frame`）：應為正片恢復後第一格。




* 四格視圖下方直接提供起點與終點的 `[-1 格]`、`[+1 格]` 微調按鈕，點擊時即時更新該格縮圖與 Frame Index。



### FR-007：同片廣告參考樣本擴展搜尋

* 針對單片出現 2～3 次同型態廣告的特性，使用者可選取任一已確認的廣告影格，點擊「設為參考樣本並搜尋相似片段」。


* 系統提取該樣本的色彩分布與版面結構特徵，快速掃描全片其餘時間軸，找出尚未標記的第 2、第 3 段同款廣告並加入候選清單。



### FR-008：手動編輯廣告區間與防呆

* 使用者可隨時手動新增廣告區間、修改起訖影格、刪除區間、合併相鄰區間或將單一區間拆分為二。


* 系統自動檢查並防止無效區間（如 `start_frame >= end_frame`、空區間或已確認區間互相重疊）。


* 未經使用者勾選標記為「已確認為廣告」，系統絕不將該候選區間納入刪除清單。



### FR-009：剪輯清單換算與跳過廣告預覽（Jump-Cut Preview）

* 系統自動將所有「已確認為廣告」的刪除區間反轉計算為「正片保留區間清單」，並在輸出前顯示將刪除的區間數、保留片段清單與預估輸出總時長。


* 提供「跳過廣告預覽」功能：點擊後從某段廣告前的指定秒數（如前 3 秒，`start_frame - 90`）播放，抵達 `start_frame` 時直接無縫跳接至 `end_frame` 繼續播放後 3 秒，讓使用者直觀確認刪除廣告後的正片銜接效果。



### FR-010：MP4 精確剪輯輸出與音訊同步

* 預設輸出設定：容器 `MP4`、視訊編碼 `H.264`（可選 CRF 品質或位元率）、音訊編碼 `AAC`、保留來源解析度與影格率特性，預設輸出檔名為 `{原始檔名}_ad_removed.mp4`（同名時先詢問是否覆寫）。


* 若來源為 VFR 影片，未經提示與同意不得強制轉為 CFR。


* 影音同步裁切：以視訊影格邊界對應之精確時間區間同步裁切音訊，透過重置各段 PTS 時間戳記處理音訊編碼延遲（Audio Priming），確保多段正片合併後無聲音跳接、爆音或累積性影音不同步。



### FR-011：專案儲存、恢復與檔案重新定位

* 支援將剪輯狀態儲存為 `.json` 專案檔（包含來源影片路徑、檔案大小與 Hash 摘要、FFprobe 資訊、候選清單、確認狀態、輸出設定及最後修改時間），不包含影片本身副本。


* 重新開啟專案時，若來源影片路徑已移動或更名，系統應彈出提示讓使用者重新指定來源影片位置，並驗證影片長度與影格數是否相符。



### FR-012：處理進度、取消與錯誤診斷

* 顯示目前執行階段（Stage 1 快速掃描 / Stage 2 區間分析 / Stage 3 邊界精確化 / FFmpeg 轉檔輸出）、進度百分比、已處理影格或時間、預估剩餘時間（ETA）。


* 提供「取消」按鈕：點擊後安全終止背景執行緒或外部 FFmpeg 子程序，清理未完成的暫存檔，且不影響原始影片。


* 若 FFmpeg 執行失敗，介面應顯示可讀的錯誤摘要與關鍵 Log 診斷資訊。



### FR-013：輸出自動驗證

* 輸出完成後自動呼叫 FFprobe 驗證：
1. 輸出檔案存在且可正常解析。


2. 視訊與音訊串流均存在。


3. 輸出總時長與「各段保留區間時長總和」一致（誤差在合理單格時間內）。


4. 時間戳記單調遞增無異常跳躍。




* 若驗證失敗，保留原始影片與 JSON 專案，並向使用者發出警告。

## 5. 三階段廣告偵測演算法規範

針對「全畫面取代、持續約 25 秒、出現 2～3 次位置不固定」設計之計算管線：

| 階段 | 處理範圍與取樣率 | 核心演算法邏輯 | 產出結果 |
| --- | --- | --- | --- |
| Stage 1<br>

<br>全片快速掃描 | • 全片時間軸（從頭到尾）<br>

<br>• 降採樣至長邊 320～480px<br>

<br>• 每秒取樣 2～5 格（可調）

 | 1. 計算相鄰取樣格之 HSV 色彩直方圖差異、亮度變化與邊緣結構差異。

<br>

<br>2. 因廣告為**全畫面取代**，切入與切出會產生顯著的全畫面特徵斷層。

 | 全片所有劇烈畫面切換之粗略時間點集合 $T_{cuts}$。

 |
| Stage 2<br>

<br>持續性分析與區間配對 | • 針對 $T_{cuts}$ 進行時間窗配對與片段內部特徵評估

 | 1. **時間窗篩選**：配對滿足 $15\text{s} \le (t_{out} - t_{in}) \le 35\text{s}$ 之切點對（以 25s 為峰值權重）。

<br>

<br>2. **廣告內部特徵評估**：檢查 $[t_{in}, t_{out}]$ 期間是否維持異於正片的圖卡版面特徵（容許底部字幕更換與局部動畫閃爍）。

<br>

<br>3. **前後正片比對與去重**：比對 $t_{in}$ 前與 $t_{out}$ 後的正片相似度，並對重疊候選區間進行合併去重。

 | 排序後的候選廣告區間清單（將最可能的 **Top 2～3 段廣告**置頂）。

 |
| Stage 3<br>

<br>局部邊界逐格精確化 | • 僅針對候選區間的 $t_{in} \pm 1\text{s}$ 與 $t_{out} \pm 1\text{s}$ 局部範圍<br>

<br>• 原始解析度**逐格解碼**<br> | 1. 快速掃描的取樣格不可直接當作剪輯邊界。

<br>

<br>2. 在 $t_{in} \pm 1\text{s}$ 與 $t_{out} \pm 1\text{s}$ 內逐格比對相鄰影格差異，精確鎖定正片最後一格（`start_frame - 1`）、廣告第一格（`start_frame`）、廣告最後一格（`end_frame - 1`）與正片恢復第一格（`end_frame`）。

 | 精確至單一 Frame 的 `[start_frame, end_frame)` 區間與對應 PTS 時間戳記。

 |

## 6. 影格區間定義與 FFmpeg 精確剪輯規範

### 6.1 半開區間與 0-based 索引規則

* 全系統統一使用 **0-based 索引** 與 **半開區間（Half-Open Interval）** `[start_frame, end_frame)` 表示待刪除的廣告區間：



$$\text{Ad Interval} = [\text{start\_frame}, \text{end\_frame})$$


* **換算範例**：假設影片總影格數為 `50000`（索引 `0` 至 `49999`），確認刪除兩段廣告 `[10000, 10750)` 與 `[30000, 30750)`：


* 實際刪除影格為索引 `10000～10749`（共 750 格）及 `30000～30749`（共 750 格）。


* 系統自動換算為 3 段**正片保留區間**：`[0, 10000)`、`[10750, 30000)`、`[30750, 50000)`。


* 避免了邊界影格重複保留或誤刪 1 格（Off-by-one error）的問題。





### 6.2 重新編碼與 FFmpeg 濾鏡管線

* H.264 / H.265 壓縮受限於 GOP 關鍵影格（I-Frame），直接 `-c copy` 無損複製無法在任意影格精確切割。


* 第一版強制以「剪輯邊界絕對正確」為最高原則，採用 FFmpeg Complex Filtergraph 進行精確裁切與重編碼：


* 視訊串流：對每個保留區間使用 `trim=start_frame=S:end_frame=E,setpts=PTS-STARTPTS`（VFR 影片則使用對應之精確時間戳記 `trim=start=T_s:end=T_e`）。


* 音訊串流：對每個保留區間使用對應時間戳記之 `atrim=start=T_s:end=T_e,asetpts=PTS-STARTPTS`。


* 片段合併：使用 `concat=n=K:v=1:a=1` 將 $K$ 段保留區間無縫拼接後輸出。




* 若未來版本新增「快速無損剪輯模式」，介面必須明確警告使用者切點將退縮至鄰近 I-Frame 而非單格精確。

## 7. 使用者介面（GUI）版面配置

採用 PySide6 設計單一主視窗，劃分為五大功能區塊：

1. **頂部：影片資訊與掃描參數列**
* 顯示來源檔名、解析度、FPS（CFR/VFR 標章）、總影格數與總時長。


* 掃描參數設定：目標廣告秒數（預設 `25s`）、搜尋範圍（預設 `15～35s`，可勾選關閉時長限制）、取樣頻率（預設 `3 fps`），以及「開始全片掃描」、「儲存／載入專案」按鈕。




2. **左上：主影片預覽與播放控制區**
* 顯示目前影格畫面、目前 `Frame Index (0-based)` 與 `PTS 時間戳記`。


* 控制列：播放／暫停、`[-30格]` `[-5格]` `[-1格]` `[+1格]` `[+5格]` `[+30格]`、指定 Frame/時間跳轉輸入框，以及「跳過廣告接合預覽（Jump-Cut Preview）」按鈕。




3. **左下：四格邊界檢查與微調區（4-Frame Boundary View）**
* 橫向並排四張縮圖：**[廣告前一格 `start-1`]**、**[廣告第一格 `start`]**、**[廣告最後一格 `end-1`]**、**[正片恢復第一格 `end`]**。


* 起點與終點下方各自配備獨立的 `[-1 格]` 與 `[+1 格]` 按鈕，讓使用者看著四格縮圖就能一鍵完成單格精確對齊。




4. **右側：候選廣告清單與樣本工具區**
* 支援切換「依優先級評分排序」與「依時間排序」。


* 每列顯示：區間編號、起訖時間與影格、持續秒數、評分、狀態下拉選單（`未確認` / `已確認為廣告` / `已排除`）。


* 底部工具鈕：「手動新增區間」、「刪除選取區間」、「合併區間」及「設為廣告樣本並搜尋相似片段」。




5. **底部：視覺化色塊時間軸與輸出區**
* 全片長條時間軸：綠色代表正片保留區、紅色代表已確認刪除之廣告區、黃色代表待確認候選區。


* 輸出面板：顯示保留片段數、預估輸出時長、輸出路徑、編碼品質設定（如 H.264 CRF 值）、進度條、「取消」與「開始輸出 MP4」按鈕。

## 8. 非功能性需求（Non-Functional Requirements）

* **跨平台相容性**：核心路徑處理全面使用 `pathlib`，外部程序呼叫使用 `subprocess` 參數陣列（避免綁定特定作業系統之 Shell 語法），確保於 macOS 與 Windows 11 行為一致。


* **效能與資源控制**：快速掃描與局部逐格解碼嚴格分離，避免將整部長片影格載入記憶體，確保在無獨立 GPU、8GB RAM 以上的環境仍能流暢運作。


* **資料安全與可恢復性**：絕不修改原始檔案；所有暫存檔集中於獨立暫存目錄，取消或異常退出時自動清理；JSON 專案可隨時保存與跨次恢復。


* **可追溯性**：每個候選區間的偵測來源（自動掃描／樣本比對／手動新增）、評分依據與人工確認狀態皆記錄於 JSON 專案中。


* **隱私保護**：100% 本機離線運算，無任何網路連線或遙測上傳需求。

## 10. 開發階段規劃（Roadmap）

* **Phase 1：精確剪輯核心與人工確認 GUI（MVP）**
* 建立 `uv` 專案結構、FFprobe 解析器、CFR/VFR 影格時間戳記索引、PySide6 播放器、四格邊界微調介面、半開區間換算邏輯，以及 FFmpeg 多段精確裁切輸出與驗證。
