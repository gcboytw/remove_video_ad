這份專案檔案架構根據 **SRS v2.1** 的五大系統模組與四階段開發藍圖設計，採用標準的 Python `src` 佈局（搭配 `uv` 管理環境），並將「核心邏輯與演算法（Core）」**與**「使用者介面（GUI）」嚴格解耦。

這樣設計最大的好處是：Phase 1 與 Phase 2 的影片分析、區間換算與 FFmpeg 精確剪輯邏輯，都可以先透過獨立腳本或 `pytest` 單獨測試驗證，不需等 GUI 全部寫完才能測，未來若要擴充 CLI 批次處理也非常容易。

## 2. 核心模組職責與對應規格 (Mapping to SRS)

這套結構直接對應規格書中的功能需求（FR）與驗收標準（AT），確保開發時每個檔案職責單一、清楚好維護：

### A. 資料模型層 (`models/`) — 確保全系統資料格式一致

* **`interval.py`**：強制實作 **0-based 半開區間 `[start_frame, end_frame)**`。內建驗證邏輯（例如拒絕 `start_frame >= end_frame`），並定義候選區間的三種狀態列舉：`UNCONFIRMED`（未確認）、`CONFIRMED_AD`（已確認為廣告）、`EXCLUDED`（已排除）。


* **`video_meta.py`**：儲存 FFprobe 解析出的資訊，包含 `is_vfr` 旗標與影格 PTS 映射表，從源頭杜絕直接用名義 FPS 亂除算時間的問題。



### B. 核心邏輯層 (`core/`) — 純 Python 邏輯，無 GUI 依賴

* **`interval_calc.py`**：負責將使用者確認的多段廣告 `[start_frame, end_frame)` 轉換成正片保留區間 `KeepSegment` 清單。這是 **AT-008（單格精確剪輯）** 最關鍵的純數學邏輯，可透過 `test_interval_calc.py` 達到 100% 測試覆蓋率。


* **`detector/` 子套件**：將三階段演算法拆分成獨立檔案（`stage1_scan.py`, `stage2_pair.py`, `stage3_refiner.py`）加上 `template_matcher.py`（同片樣本搜尋）。日後若你想微調 Stage 2 的圖卡穩定度評分公式，只需修改 `stage2_pair.py`，完全不會動到其他程式碼。


* **`exporter.py`**：專門負責組裝 FFmpeg 的 `trim` / `atrim` / `setpts` / `concat` 濾鏡指令，並透過 `subprocess.Popen` 讀取 FFmpeg 的 `stderr` / `-progress` 輸出，即時將進度百分比傳回給呼叫端。



### C. 使用者介面層 (`gui/`) — 視圖與背景工作分離

* **`workers.py`**：將耗時的「全片三階段掃描」與「FFmpeg 轉檔輸出」封裝在 `QThread` 中執行，確保掃描與轉檔時 GUI 介面不會卡死（Not Responding），並能隨時響應使用者的「取消」按鈕（對應 **FR-012**）。


* **`widgets/boundary_view.py`**：獨立封裝最重要的人工確認核心——**四格邊界檢查視圖**（`start-1`, `start`, `end-1`, `end`）與 `[-1格][+1格]` 按鈕（對應 **FR-006**）。



### D. 測試與合成素材層 (`tests/`) — 解決測試影片來源問題

* **`generate_test_video.py`**：遵循規格書中「先用已知影格內容的短影片驗證」的建議，這支腳本會直接呼叫 FFmpeg 的 `testsrc` 與 `drawtext` 濾鏡，自動生成一部每一格都印有 `Frame Index (0-based)` 浮水印與蜂鳴器對時音效的合成影片（例如插入兩段 25 秒的紅底圖卡廣告），讓你不用拿龐大的真實影片就能在幾秒鐘內驗證 **AT-008（0 殘留、0 遺失）** 與 **AT-009（影音同步）**。

## 3. `pyproject.toml` 初始配置規劃 (使用 `uv`)

配合你的開發環境，專案根目錄的 `pyproject.toml` 建議配置如下，固定依賴套件版本並提供清晰的啟動指令：

```toml
[project]
name = "video-ad-remover"
version = "0.1.0"
description = "Semi-automatic frame-accurate video ad detector and remover using Python, OpenCV, and FFmpeg."
readme = "README.md"
requires-python = ">=3.12"
dependencies = [
    "numpy>=2.0.0",
    "opencv-python>=4.10.0",
    "pyside6>=6.7.0",
    "scenedetect>=0.6.4",
]

[dependency-groups]
dev = [
    "pytest>=8.3.0",
    "ruff>=0.6.0",
]

[project.scripts]
ad-remover = "video_ad_remover.main:main"

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

```
